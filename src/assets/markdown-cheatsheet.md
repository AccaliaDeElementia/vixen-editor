# Writing markdown

Everything below is live markdown. What you see here is what
the editor will show you as you type it.

## Headings

# A title

## A section

### A subsection

## Emphasis

*italic*, **bold**, ~~struck through~~, and `inline code`

## Lists

- a bullet
- another one
  - and one nested

1. numbered
2. and the next

- [ ] still to do
- [x] already done

## Links and pictures

[a link to another document](other.md)

![a picture beside it](photo.png)

<https://example.com>

A bare address works too: https://example.com

## Quotes

> A quoted line.
> It can run on.

## Code

```js
const fenced = 'code'
```

## Tables

| left | middle | right |
| :--- | :----: | ----: |
| a    |   b    |     c |

## Callouts

TODO: something to come back to

FIXME: something that needs mending

NOTE: something worth remembering
